# Python & Tech Quiz App

A simple command line quiz app written in Python which tests the users knowledge of the language and some basic Technology Concepts.

## Features

- Multiple choice quiz questions

- Python and Technology related

- Four possible options for each question

- Accepts A, B, C or D as answers

- Automatically checks and marks answers

- Keeps track of the score

- Calculates percentage

- Gives feedback based on the marks

- Shows the correct answer for wrong choices

## Technologies used

- Python

### How it Works

1. The quiz questions are stored in a Python Dictionary

2. The keys of the dictionary are the questions which have four multiple choice options and the correct answer

3. The user is prompted to enter A, B, C or D as an answer

4. Then the entered answer is compared against the correct answer

5. If the answer is correct the score increases

6. Finally, after all the questions are answered the percentage is calculated

7. The user gets a feedback based on the percentage of marks scored 🥇🥈🥉

### The Concepts

The current app contains questions on

Python data types

For instance, the app quizzes the user on exponentiation in Python, Python Dictionaries and CPU. 😌
